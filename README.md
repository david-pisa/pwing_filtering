# PWING VLF Data Processing and Filtering

This repository contains a Python-based data processing pipeline for Very Low Frequency (VLF) data from the PWING project. It reads raw binary data files (`.ANG` format), applies a sequence of advanced digital filters, computes spectral matrices, derives Stokes polarization parameters, and outputs the final processed data into NASA Common Data Format (CDF) files.

## Features

- **Raw Data Ingestion**: Reads binary `.ANG` files containing multi-channel VLF recordings.
- **Advanced Filtering Pipeline**: Sequences three specialized filters to remove distinct types of electromagnetic noise and interference.
- **Spectral & Polarization Analysis**: Computes Short-Time Fourier Transforms (STFT) to calculate spectral matrices and derives Stokes parameters (degree of polarization, ellipticity, and angles of the semi-major axis of the polarization ellipse, $\tau$).
- **Parallel Processing**: Uses Python's `multiprocessing.Pool` to process multiple large VLF files concurrently.
- **Standardized Output**: Saves the resulting spectrograms and polarization parameters directly into NASA CDF files using `xarray` and `cdflib` for broad compatibility with space physics tools.

## Filtering Modules

The `src/pwing_filtering` directory contains the core filtering scripts:

1. **`PLHRfilter.py`**: Power Line Harmonic Radiation (PLHR) filter. Detects and removes power line harmonics (e.g., 50 Hz, 100 Hz) up to a configurable maximum frequency. It dynamically checks for true line frequencies to apply accurate notch filters.
2. **`attenuateVLFstations.py`**: Attenuates known strong VLF transmitter stations (e.g., the Russian Alpha navigation system, submarine communications). This filter prevents the sidelobes of these powerful narrow-band transmitters from contaminating the broader spectrum. It uses adaptive notch filtering with Kaiser windows.
3. **`removepeakvalues.py`**: An adaptive filter designed to remove impulsive atmospheric noise (sferics) generated by lightning strikes. It tracks sferic levels dynamically to minimize data loss while effectively removing high-amplitude peaks.
4. **`ANG_processing_v02.py`**: The main execution script. It orchestrates reading the data, applying the aforementioned filters in sequence, calculating the spectral data, and exporting to CDF format.

## Installation

Ensure you have Python 3 installed. You can install the required third-party dependencies using:

```bash
pip install -r requirements.txt
```

The required packages include:
- `numpy`
- `scipy`
- `cdflib`
- `xarray`

## Usage

To process data, modify the `ANG_processing_v02.py` script to point to your data directories:

1. Open `ANG_processing_v02.py`.
2. Update the `idir` and `odir` variables to your desired input and output directories (where CDF files will be found and saved, respectively).
3. Adjust `num_workers` in `process_multiple_files_parallel` to match your CPU's capabilities for parallel processing. Default value is `max(1, os.cpu_count() - 1)`.
4. Run the script:

```bash
python src/pwing_filtering/ANG_processing_v02.py
```
